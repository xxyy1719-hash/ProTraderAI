# ProTrader AI — نسخه 0.2.0

## قابلیت‌های پیاده‌سازی‌شده
- اپ اندروید بومی با Kotlin و رابط فارسی
- انتخاب XAU/USD، EUR/USD، GBP/USD، USD/JPY و XAG/USD
- دریافت قیمت از Twelve Data
- دریافت کندل و تحلیل ۸ تایم‌فریم: MN، W1، D1، H4، H1، M15، M5، M1
- محاسبه EMA20/EMA50، RSI14، ATR14، حمایت و مقاومت ۳۰ کندل اخیر
- گزارش هم‌سویی تایم‌فریم‌های بالاتر و تایم‌فریم‌های ورود
- خروجی محافظه‌کارانه NO TRADE در صورت نبود هم‌سویی کافی
- هیچ سفارش معاملاتی ارسال نمی‌شود

## هشدار مهم درباره کیفیت تحلیل
امتیاز نمایش‌داده‌شده «امتیاز هم‌سویی روند» است و احتمال برد یا نرخ موفقیت نیست. این نسخه هنوز تشخیص واقعی Order Block، FVG، Liquidity Sweep، ساختار ICT/SMC، اخبار، حجم و Order Flow را پیاده‌سازی نکرده است. خروجی آن ابزار کمکی آزمایشی است، نه سیگنال آماده اجرا.

## ساخت APK
در محیط توسعه Android Studio پروژه را باز کنید و از مسیر Build > Build APK(s) خروجی بگیرید.
یا پروژه را در مخزن GitHub قرار دهید و Workflow موجود در `.github/workflows/android.yml` را اجرا کنید. فایل APK در Artifact گردش‌کار قرار می‌گیرد.

## داده بازار
یک کلید معتبر Twelve Data لازم است. آن را در خود اپ وارد کنید. برای اجرای تحلیل ۸ تایم‌فریم، سرویس باید دسترسی به همه intervalها و سهمیه کافی داشته باشد. خطا یا محدودیت API باعث توقف تحلیل می‌شود؛ اپ در این حالت سیگنال حدسی تولید نمی‌کند.

## امنیت و اتصال MT5
این نسخه API key را به فضای ابری خود اپ ارسال یا ذخیره نمی‌کند؛ درخواست مستقیم از گوشی به Twelve Data ارسال می‌شود. اتصال MT5 هنوز پیاده‌سازی نشده است. طراحی اتصال بعدی بر پایه پل ویندوزی فقط‌خواندنی LiteFinance MT5 خواهد بود؛ هیچ رمز عبور یا مجوز معامله‌ای نباید در اپ وارد شود.
