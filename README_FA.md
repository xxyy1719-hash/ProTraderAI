# ProTrader AI — نسخه 0.2.0

پروژه اندروید بومی Kotlin با رابط فارسی. نسخه فعلی یک نمونه اولیه برای دریافت داده Twelve Data و تحلیل روند در تایم‌فریم‌های MN، W1، D1، H4، H1، M15، M5 و M1 است.

## قابلیت‌های نسخه
- نمادها: XAU/USD، EUR/USD، GBP/USD، USD/JPY و XAG/USD
- EMA20/EMA50، RSI14، ATR14 و حمایت/مقاومت ۳۰ کندل اخیر
- نمایش هم‌سویی تایم‌فریم‌های بالاتر و تایم‌فریم‌های ورود
- عدم تولید سیگنال در صورت نبود داده معتبر یا هم‌سویی کافی
- عدم ارسال سفارش معاملاتی

## محدودیت‌ها و هشدار
این نسخه هنوز OB/FVG، Liquidity Sweep، ساختار ICT/SMC، اخبار، حجم/Order Flow، اتصال MT5 و مدیریت معامله را پیاده‌سازی نکرده است. امتیاز، هم‌سویی روند است و احتمال برد نیست. خروجی ابزار کمکی آزمایشی است و نباید بدون اعتبارسنجی مستقل مبنای معامله قرار گیرد.

برای تحلیل، کلید معتبر Twelve Data و سهمیه کافی لازم است. کلید در این نسخه فقط برای درخواست مستقیم از گوشی به API استفاده می‌شود.

## ساخت
در Android Studio پروژه را باز کنید یا GitHub Actions را اجرا کنید. خروجی Debug APK در Artifact گردش‌کار ذخیره می‌شود.
