# ProTrader AI

Persian-language Android market-analysis prototype.

- Current source version: **v0.2.0**
- Android project is located at the repository root (`app/`, Gradle build files).
- Build workflow: `.github/workflows/android.yml`
- See `README_FA.md` for features, limitations, and build instructions.

This is an analytical prototype only. It does not place trades and its trend-alignment score is not a win probability.
